# Hamammi Auto Queue Fortnite

Bot de **autocola para Fortnite** con instalador ejecutable. Pulsa por ti los botones para repetir partidas sin que tengas que tocar nada: **Listo**, **Jugar de nuevo** y **Volver a la sala**.

## Características
- Reconoce los botones en pantalla en **español e inglés**.
- Botón único **Start / Stop**.
- **Registro de actividad en vivo**.
- Tiempos configurables: espera en el lobby y espera para volver a ponerse en cola.
- Instalador ejecutable, sin tener que instalar Python.

## Descargar
Ve a [Releases](../../releases/latest) y descarga el instalador (`.exe`).

## Instalar
1. Descarga el instalador desde Releases.
2. Ábrelo y sigue los pasos.
3. Si Windows muestra un aviso de SmartScreen, pulsa **Más información → Ejecutar de todas formas**.

## Cómo se usa
1. Abre Fortnite y deja el juego visible en pantalla.
2. Abre Auto Queue y, si quieres, ajusta los tiempos en **Setup**.
3. Pulsa **Start**.
4. Para pararlo, pulsa **Stop**.
